# Juegos para pensar

Tres juegos para trabajar el pensamiento computacional y matemático en el aula.

- El misterio del campus. Deducción con pistas y una cuadrícula.
- Bridg-It. Conexión de extremos para dos jugadores.
- Triángulos. Cierre de triángulos y conteo de puntos para dos jugadores.

## Publicar en GitHub Pages

1. Creá un repositorio en GitHub.
2. Subí el contenido de esta carpeta a la raíz del repositorio. index.html debe quedar en esa raíz.
3. En Settings > Pages, elegí Deploy from a branch.
4. Seleccioná la rama main y la carpeta / (root), y guardá.
5. Abrí la dirección que muestre GitHub Pages cuando termine la publicación.

No requiere instalación ni compilación. Todos los enlaces son relativos y funcionan dentro de la dirección del repositorio.

## Uso en clase

La portada incluye habilidades de pensamiento computacional y matemáticas, junto con una propuesta de reflexión para docentes. Bridg-It y Triángulos se juegan por turnos en el mismo dispositivo.

## Material de referencia

El misterio del campus adapta el caso introductorio de Murdle, de G. T. Karber, a partir del material aportado. La atribución también figura dentro del juego.
